# 筋トレ記録アプリ

スマホのブラウザで使える筋トレ記録アプリです。インストール不要・サーバー不要で、データは端末内に保存されます。

## できること

- **記録**：種目を追加して、セットごとに重量と回数を入力。✓ でセット完了
  - 前回の同じ種目の記録を表示し、セット内容を自動で引き継ぎ
  - 日付を変えれば過去の記録も入力・編集できる
- **レストタイマー**：セット完了で自動スタート（±15秒調整、終了時に音とバイブ）
- **履歴**：日ごとのトレーニング内容を一覧表示
- **分析**：種目ごとの最大重量・推定1RM（Epley式）・総ボリューム、1RMの推移グラフ、直近7日間のセット数
- **設定**：タイマー秒数の変更、バックアップの保存／読み込み（JSON）

※ 集計の対象は ✓ を付けた「完了セット」だけです。

## 使い方

### パソコンで試す

```bash
cd workout-app
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。

### スマホで使う

GitHub Pages などの https のサイトに `workout-app` フォルダを置いて、スマホで開きます。
「ホーム画面に追加」すると普通のアプリのように起動でき、オフラインでも使えます。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面のレイアウト |
| `style.css` | 見た目（ダークモード対応） |
| `app.js` | アプリの動き（記録・タイマー・グラフなど） |
| `sw.js` | オフライン対応 |
| `manifest.json` / `icon.svg` | ホーム画面に追加したときの名前とアイコン |
