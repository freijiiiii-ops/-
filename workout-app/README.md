# 筋トレ記録アプリ

スマホのブラウザで使える筋トレ記録アプリです。インストール不要・サーバー不要で、データは端末内に保存されます。

公開URL：https://freijiiiii-ops.github.io/-/

## できること

- **カレンダー（ホーム）**：トレーニングした日に部位の色の点、メモした日に📝が付く。日付をタップでその日の記録へ
- **部位から種目を選ぶ**：胸・背中・肩・腕・脚・腹/体幹の大きなボタン → 種目一覧（オリジナル種目も追加可）
- **見本の動き**：種目ごとに15秒の動作アニメーション（回数カウント・フォームのポイント付き）と、YouTube動画検索ボタン
- **セット記録**：重量・回数を入力して ✓。前回の記録を自動で引き継ぎ、レストタイマーが自動スタート
- **たくさん褒める**：セット完了・種目完了・自己ベスト更新・メモ記録のたびに褒めメッセージやお祝い演出
- **メモ・カロリー**：体重、睡眠（就寝・起床時刻）、食事（内容・kcal）、活動（ウォーキング等）、ひとことメモ
  - 基礎代謝（Mifflin-St Jeor式）、運動の消費カロリー（METs）、1日の消費カロリーの目安、摂取との差
- **分析・アドバイス**：週（直近7日）/月（直近30日）の部位ごとのセット数と目安、少ない部位・やっていない日数・押す/引くのバランス・負荷の軽さ・前期間との比較をアドバイス。推定1RMと体重のグラフ
- **マイページ**：ニックネーム・性別・年齢・身長・体重・目標、BMI・基礎代謝・タンパク質の目安、タイマー設定、バックアップ

※ 集計の対象は ✓ を付けた「完了セット」だけです。カロリー等の計算値は目安です。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面のレイアウト |
| `style.css` | 見た目（ダークモード対応） |
| `exercises.js` | 部位・種目（フォームのポイント・アニメーション定義）・活動・ほめ言葉のデータ |
| `figure.js` | 見本の動きのアニメーション |
| `app.js` | アプリの動き（記録・カロリー計算・分析など） |
| `sw.js` | オフライン対応 |
| `manifest.json` / `icon.svg` | ホーム画面に追加したときの名前とアイコン |

## パソコンで試す

```bash
cd workout-app
python3 -m http.server 8000
```
