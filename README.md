# Instagram 収益化ガイド

Instagram で収益を得るための方法と、ゼロから始める手順をまとめたものです。

> 注意: Instagram の収益化機能の条件（フォロワー数・年齢・対象国など）はよく変わります。
> 最新の条件はアプリの **プロフェッショナルダッシュボード → 収益化ステータス** で確認してください。

---

## 1. 収益化の主な方法

| 方法 | 内容 | フォロワーの目安 | 収益の大きさ |
| --- | --- | --- | --- |
| **PR案件（企業タイアップ）** | 企業の商品やサービスを紹介して報酬をもらう | 数千〜（マイクロインフルエンサーも需要あり） | ◎ 最も大きい |
| **アフィリエイト** | 楽天ROOM・Amazonアソシエイト・ASPのリンク経由で売れたら報酬 | 0〜 | ○ |
| **自分の商品・サービス販売** | 物販、デジタル商品（テンプレ・レシピ集）、講座、相談、予約制サービスなど | 0〜（熱量のあるファンが少数でも可） | ◎ 利益率が高い |
| **公式の収益化機能** | サブスクリプション、ギフト、ライブのバッジなど | 機能ごとに条件あり | △〜○ |
| **集客ツールとして使う** | 店舗・教室・サロン・フリーランスの仕事への集客 | 地域や専門によっては数百でも効果あり | ◎ |

**おすすめの順番:** アフィリエイト or 自分の商品 → フォロワーが増えたら PR 案件 → 条件を満たしたら公式機能を追加。

---

## 2. 始める手順

### ステップ1: ジャンル（テーマ）を決める
- 「誰の・どんな悩みを解決するアカウントか」を一文で言えるようにする
  - 例: 「忙しい共働き夫婦向けの 15 分夕飯レシピ」
- お金になりやすいジャンル: 美容・コスメ、ファッション、料理、育児、インテリア、旅行、ダイエット・健康、お金・副業、勉強法、ペット
- 自分が **続けられる・詳しい** ジャンルを選ぶことが最重要

### ステップ2: プロアカウントに切り替える
- 設定 → アカウントの種類とツール → **プロアカウントに切り替える**（クリエイター or ビジネス）
- インサイト（分析）・収益化機能・問い合わせボタンが使えるようになります

### ステップ3: プロフィールを整える
- アイコン: 顔 or 一目でジャンルがわかる画像
- 名前欄: 「名前｜ジャンルのキーワード」（検索に引っかかりやすくなる）
- 自己紹介: 誰向けか / 何が得られるか / 実績 を 3 行程度で
- リンク: リンクまとめ（lit.link など）や販売ページ

### ステップ4: 投稿する
- **リール（短尺動画）** が新規フォロワー獲得に最も効く
- **保存される投稿**（まとめ・比較・手順・チェックリスト形式のカルーセル）がおすすめに載りやすい
- **ストーリーズ** でファンとの距離を縮め、リンクで商品・アフィリエイトへ誘導
- 頻度の目安: 最初の 3 か月は週 3〜5 投稿 + ストーリーズ毎日
- インサイトで「保存数・シェア数・リーチ」が多い投稿を分析し、似た企画を増やす

### ステップ5: 収益化を始める
- **アフィリエイト:** もしもアフィリエイト・A8.net・楽天アフィリエイトなどに登録し、ストーリーズのリンクやプロフィールリンクで紹介
- **PR案件:** プロフィールに「お仕事のご依頼は DM へ」と記載。キャスティングサービスやインフルエンサーマッチングサービスに登録する
- **自分の商品:** 小さく始める（例: 500〜3,000 円のデジタル商品、オンライン相談）

---

## 3. PR案件の単価の考え方

よく使われる目安は **フォロワー単価 1〜4 円程度**（例: 1 万フォロワーで 1〜4 万円/投稿）。
実際はエンゲージメント率（いいね・保存・コメントの割合）やジャンルで大きく変わります。
フォロワー数より **反応率の高さ** が評価される傾向です。

---

## 4. 必ず守ること

- **ステマ規制:** PR 投稿には「#PR」「広告」などを明記する（2023年10月から景品表示法で規制対象）。Instagram の「タイアップ投稿」ラベルも活用
- **確定申告:** 副業の所得が年間 20 万円を超えると原則として確定申告が必要（会社員の場合。住民税の申告は金額にかかわらず必要）
- **やってはいけないこと:** フォロワー購入、自動いいね・自動フォローツール（アカウント停止やリーチ低下の原因）、他人の写真・音楽の無断使用
- **詐欺に注意:** 「フォロワーが増える」「簡単に稼げる」系の高額コンサルや、DM で届く怪しい案件（先にお金を払わせるもの）は避ける

## 5. 30日アクションプラン

| 期間 | やること |
| --- | --- |
| 1週目 | ジャンル決定、プロアカウント化、プロフィール作成、同ジャンルの伸びているアカウントを 10 個研究 |
| 2週目 | リール 3 本 + カルーセル 2 本を投稿、ストーリーズ毎日 |
| 3週目 | インサイトを見て反応の良い型を特定、アフィリエイト（ASP）に登録 |
| 4週目 | 伸びた型を量産、ストーリーズで初のアフィリエイト紹介、プロフィールに「お仕事依頼は DM へ」を追加 |

## 次に決めること

具体的な戦略を立てるために、次の点を整理するとよいです:

1. 発信したいジャンル（好きなこと・得意なこと・仕事）
2. 現在のフォロワー数と投稿内容
3. 使える時間（1日・1週間あたり）
4. 目標金額（例: 月 3 万円、月 10 万円）
5. 顔出しの可否
